# Rubber Ducky Scripts
A collection of scripts to run on a rubber ducky to attempt to exploit vulnerabilities, assessing the state of the device's security to be able to improve it.

## Implementation
Simply clone the repo, then push the desired payload onto your rubber ducky flash drive HID device. From there you can plug your ducky into a computer and watch the results. Some files may require variable value replacement on a case by case basis before being moved to the ducky to be able to have more control over what is being targeted on the computer.

Clone repo:
```git clone https://github.com/LiamFCode/RubberDuckyScripts.git```
